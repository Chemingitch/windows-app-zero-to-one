# 踩过的坑

按"会卡多久"排序。

## 1. 自签证书 ≠ 别人能正常安装

最容易误解的一条。自签签名后**自己电脑**显示 `Valid`，发给别人照样弹
「Windows 已保护你的电脑」蓝框。不少人以为签了名就完事，结果用户以为中毒。

- 交付时必须提前说明"点更多信息 → 仍要运行"
- 真要无感安装只能买 OV/EV 证书
- 详见 `signing-and-smartscreen.md`

## 2. 不加时间戳，证书过期后全部失效

签名时不打时间戳，证书到期那天所有已发出的 exe 都变成"签名无效"。
脚本已默认加时间戳（DigiCert 服务器），**不要**为了省几秒加 `--no-timestamp`。
离线环境确实签不了时间戳时，要意识到这是有代价的。

## 3. Get-AuthenticodeSignature 返回 UnknownError

不一定是签名失败，多数是**证书链不受信**——自签证书没进本机受信任根。
本脚本生成证书时会自动加入 `CurrentUser\Root`；换台机器看同一文件就会是 `UnknownError`，
这是预期行为，不是 bug。

## 4. PyInstaller 的两大代价

- `--onefile` 每次启动解压到临时目录，**慢 1-3 秒**，用户会觉得卡
- **杀软误报率高**，解压行为像加壳

要分发给别人时，这两条比"开发快"更重要。能上 Go 就别用 PyInstaller 发外网。

## 5. 控制台程序双击一闪而过

有输出的程序直接双击运行，窗口关掉就啥也看不见。
要么在末尾加暂停，要么改用 `--noconsole` 配 GUI，要么明确告诉用户从命令行跑。
**别等用户反馈"程序没反应"才想到。**

## 6. .NET 首次 publish 很慢

首次要还原 NuGet 包，几分钟很正常，别以为卡死。
`--self-contained` 体积 60-70MB 起步，`PublishTrimmed=true` 可瘦身但有反射风险。

## 7. Go 忘了 CGO_ENABLED=0

默认 Windows 上其实不启用 cgo，但只要引入某些依赖（sqlite、某些 GUI 库）就会启用，
产物变成依赖 MinGW DLL 的非静态文件。脚本已强制 `CGO_ENABLED=0`，手写命令时别漏。

## 8. 中文路径打包失败

PyInstaller 对中文用户名/中文项目路径敏感，容易报编码错误。
项目路径保持全英文最省事；`%APPDATA%` 下写数据则没问题。

## 9. 没有自动更新机制

exe 不像应用商店，发出去就没有更新通道。
要么自己做版本检查（联网比对版本号 → 提示下载），要么接受用户手动换包。
**换包时签名必须一致**，否则用户还得先卸载。

## 10. 路径含空格

PowerShell 单引号内要转义 `'` 为 `''`；Python 里传命令用列表而非拼接字符串。
本脚本的 `q()` 处理了 PowerShell 转义，手写 PS 命令时要记得。
